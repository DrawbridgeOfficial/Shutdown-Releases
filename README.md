# 🪓 Shutdown Utility — CitaDev

Utilitar Windows pentru controlul alimentării calculatorului: **oprire, repornire, sleep, hibernare, blocare ecran, deconectare** — plus **programare oprire/repornire cu countdown live**.

## 📥 Descărcare

Descarcă ultima versiune din pagina **[Releases](../../releases)**:

> **[`ShutdownApp.exe`](../../releases/latest)** — self-contained, ~69 MB, nu necesită .NET instalat.

## 🖥️ Cerințe

- Windows 10 / 11 (x64)

## ✨ Funcționalități

- ⏻ **Oprire acum** — shutdown nativ Windows
- ⟳ **Repornire acum** — restart nativ Windows
- 🌙 **Sleep** / 💤 **Hibernare**
- 🔒 **Blochează ecranul** / ↪ **Deconectare sesiune**
- ⏱ **Programare** cu countdown live, presetări (15m / 30m / 1h / 2h / 4h) și anulare oricând
- Programarea supraviețuiește închiderii aplicației (timer nativ Windows)

## 🚀 Utilizare

1. Descarcă `ShutdownApp.exe` din [Releases](../../releases/latest)
2. Rulează (dublu-click) — nu necesită instalare
3. Alege acțiunea sau programează o oprire cu countdown

## 🔒 Confidențialitate

Aplicația nu colectează date, nu accesează rețeaua și rulează complet local.

## 🛠️ Dezvoltare

Codul sursă se găsește în repo-ul privat al proiectului. Fiecare versiune (tag `v*`) declanșează un build automat GitHub Actions care publică exe-ul ca Release.
